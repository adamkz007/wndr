Changelog

What’s new in each release of Wndr.

v0.4.0 Latest July 2026
  • Faster everywhere. Library updates are now incremental — renaming, deleting, tagging, and importing no longer reload the entire library, so large collections stay responsive.
  • Smoother lists. Removed file-system reads from row rendering and cache thumbnail and size metadata, eliminating scroll hitches.
  • Quicker imports. Drag-and-drop import syncs only the new documents instead of refetching everything.
  • Leaner and native. Streamlined to a focused macOS-only build with shared formatters and lower memory churn.
  • Performance instrumentation. Added internal signposts and benchmarks to keep launch, search, and import times within budget.
v0.3.0 May 2026
  • Native macOS PDF toolbar with page navigation, zoom presets, and display modes.
  • Document thumbnails, info popover with editable metadata, and a library status bar.
  • Color-coded tags with an automatic macOS-style palette.
v0.2.0 May 2026
  • Markdown notes with live preview, formatting toolbar, and templates.
  • PDF highlighting with six colors plus collections and tags for organization.
  • Content search across filenames and notes.
